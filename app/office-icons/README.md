# Microsoft Office product icons

These local SVG assets are derived from Microsoft's Office/Fabric product icon set and are used
only to identify and launch their corresponding Microsoft applications in the Office panel.

Source pattern:
`https://static2.sharepointonline.com/files/fabric/assets/brand-icons/product-fluent/svg/<app>_48x1.svg`
